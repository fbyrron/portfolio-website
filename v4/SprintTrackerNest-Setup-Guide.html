Before you start

One file is the whole install.

The extension runs on the Node.js that is already built into Kiro and VS Code. It has no extra packages.

You need

  • Kiro or VS CodeVersion 1.85 or later.
  • The .vsix fileIt is built into this page. Use the Download button.
  • A Jira API tokenFree to create from your Atlassian account.
  • Your scrum board IDThe number at the end of your board URL.

You don’t need

  • PythonNothing in the extension uses it.
  • Node.js or npmThe editor already includes a runtime.
  • Git or the source codeThe .vsix holds the compiled extension.
  • Admin rightsExtensions install for your user only.

Your API token

Your token goes to SecretStorage. Nowhere else.

SecretStorage is the editor’s built-in vault for passwords and tokens. Your operating system encrypts it.

1. You paste it

The prompt hides what you type. The token is never shown on screen.

2. Jira checks it

One HTTPS call to your Jira site confirms who you are. If it fails, nothing is saved.

3. SecretStorage keeps it

Encrypted with keys your OS protects.

Windows: DPAPImacOS: KeychainLinux: keyring
WhatStored inEncryptedSent anywhere?
API tokenSecretStorageYes, by the OSOnly to your Jira site, over HTTPS
Site URL, email, display nameExtension state (globalState)No, not secretNo
Board ID, project keyExtension state (globalState)No, not secretNo
The token is never in: settings.json Log files The .vsix file Git or this page

Why connect again on each desktop? SecretStorage belongs to one user on one machine. Settings Sync does not copy it. Disconnect Jira wipes the token and all saved values.

Help

Updates and fixes.

Updating to a new version

Install the new .vsix the same way as step 2. It replaces the old version.

Your Jira connection and board ID stay in place. No need to reconnect.

Check the file is intact (optional). Run Get-FileHash .\sprintpulse-0.1.0.vsix in PowerShell. It should start with 5D46FE797A8F.
No rocket icon after install

Run Developer: Reload Window. Then open the Extensions view and check that SprintTrackerNest is listed and enabled.

“Could not connect to Jira”

Check that the email matches your Atlassian account. Tokens can expire, so create a new one if needed.

On a company network, connect to the VPN first.

“Connect to Jira first, then set a board ID”

Do step 4 before step 5. The board ID must be a whole number, like 4069.

Status bar says “needs refresh”

The last automatic update failed, so you are seeing older data. Click the refresh icon in the Current Sprint view. Check your network if it keeps happening.

The terminal says “command not found”

The editor’s shell command isn’t on your PATH. Use the Install from VSIX… menu instead. It does the same thing.
