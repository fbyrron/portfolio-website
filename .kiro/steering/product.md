# Product Overview

This is a personal portfolio website for Ernest Byrron Flores, showcasing professional identity, projects, and contact information.

## Purpose
- Present professional profile and personal brand
- Display project portfolio with descriptions
- Provide contact methods (email, GitHub, LinkedIn)
- Create engaging user experience with smooth animations

## Key Sections
- Hero: Introduction with name and tagline
- About: Brief professional description
- Projects: Grid-based project showcase
- Contact: Links to email and social profiles
