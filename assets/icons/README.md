## Icon Specifications
- **Format**: SVG (vector)
- **Size**: 64px × 64px
- **Style**: Consistent visual style (official brand logos recommended)
- **Color**: Full color (will be displayed on dark background)
- **Alt Text**: Each icon should have descriptive alt text (e.g., "Dart logo", "Java logo")

## Usage
Icons are displayed in a responsive CSS Grid:
- Desktop: 5 icons per row (3 rows total)
- Tablet: 4 icons per row
- Mobile: 3 icons per row

## Hover Effects
- Scale: 1.1x on hover
- Glow: Purple box-shadow effect
- Transition: 0.3s ease
