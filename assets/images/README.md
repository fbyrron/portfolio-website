# Images Directory

This directory contains illustrations and mockups for the portfolio website.

## Required Assets

### Character Illustration
- **Filename**: `character-illustration.svg`
- **Description**: Illustration of Ernest with a laptop for the hero section
- **Format**: SVG (vector)
- **Recommended Size**: 400px × 400px
- **Usage**: Hero section left column

### Project Mockup
- **Filename**: `ecommunity-mockup.png`
- **Description**: Mobile phone mockup showing the Ecommunity.ph app interface
- **Format**: PNG
- **Recommended Size**: 300px × 600px (or higher resolution for retina displays)
- **Usage**: Featured project section right column
- **Note**: Should include lazy loading attribute

### FlutterFlow Badge
- **Filename**: `flutterflow-badge.svg`
- **Description**: "Built in FlutterFlow" badge logo
- **Format**: SVG (vector)
- **Recommended Size**: 120px × 40px
- **Usage**: Hero section bottom right corner (absolute positioned)

## Notes
- Use SVG format for scalable graphics (character illustration, badge)
- Use PNG format for screenshots/mockups with transparency
- Consider WebP format with PNG fallback for optimized loading
- All images should have descriptive alt text for accessibility
